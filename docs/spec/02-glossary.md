## ドメイン用語

| 用語 | 英語 | 定義 |
|------|------|------|
| ボード | Board | カンバン全体を表すコンテナ。MVP では 1 インスタンスのみ |
| 列 | Column / Lane | ボード内の縦方向区分。タスクの状態を表す |
| カード | Card | 個々のタスク。タイトル・説明等の属性を持つ |
| ペタッと操作 | Petatto action | カードを直感的かつ素早く配置・移動する操作（MVP: コンボボックス移動、M2: DnD） |

## SDD 用語

| 用語 | 定義 |
|------|------|
| 要件 | システムが満たすべき条件。`FR-` / `NFR-` で識別 |
| 受け入れ基準 | 要件が満たされたと判断するための検証可能な条件。`AC-` で識別 |
| データ契約 | 永続化形式・スキーマの約束。`DC-` で識別 |
| UI 契約 | 画面操作・表示の約束。`UC-` で識別 |
| トレーサビリティ | 要件 → ストーリー → テスト → 実装の対応関係 |

## 技術用語

| 用語 | 定義 |
|------|------|
| MVP | Minimum Viable Product。M1 マイルストーンで提供する最小機能セット |
| PyInstaller | Python アプリを Windows `.exe` にパッケージするツール |
| 永続化パス | `%USERPROFILE%\.petatto-kanban\board.json` |

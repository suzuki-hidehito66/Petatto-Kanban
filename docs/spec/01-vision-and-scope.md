## 1. ビジョン

**「タスクをペタッと貼って、サッと進める」**

Petatto-Kanban は、**単一ユーザー向けの独立した Windows デスクトップアプリケーション**（`.exe`）である。  
カンバン方式でタスクを管理し、付箋を貼るような軽快な操作感を核に、1 人のユーザーが自分の PC 上で完結して利用できる。

---

## 2. 初期スコープ（M1 MVP）の定義

> **初期スコープ = 単一ユーザーの独立したデスクトップアプリケーション（`.exe`）**

| 属性 | 定義 |
|------|------|
| 利用形態 | **単一ユーザー** — 1 人が 1 台の PC で利用。アカウント・ログインなし |
| アプリ形態 | **独立デスクトップアプリ** — サーバー・ブラウザ・常時ネットワーク不要 |
| 配布形式 | **Windows `.exe`** — PyInstaller による単一実行ファイル |
| データ所在 | **ローカルのみ** — ユーザーの PC 内 JSON ファイルに保存 |
| 同時利用 | **なし** — マルチユーザー・共同編集・クラウド同期は対象外 |

この定義は M1 マイルストーン全体の上位制約となり、機能追加の判断基準とする。

---

## 3. 目的

| # | 目的 | 成功指標 |
|---|------|----------|
| P-1 | 直感的なタスク管理 | 初回利用者が 5 分以内にカード作成・移動を完了できる |
| P-2 | 独立動作 | `.exe` 実行後、ネットワーク・外部サービスなしで全機能が利用できる |
| P-3 | 手軽な配布 | Windows `.exe` 1 ファイルで配布・起動できる（インストーラ不要） |
| P-4 | 単一ユーザー完結 | 1 ユーザー・1 PC・1 データファイルでタスク管理が完結する |

---

## 4. 対象ユーザー（初期スコープ）

> 初期スコープは **単一ユーザー** に限定する。チーム利用・共同編集は M3 以降の検討事項。

| ペルソナ | ニーズ | 関連 US |
|----------|--------|---------|
| 個人開発者 | 自分の PC 上で TODO をシンプルに管理 | US-001, US-003 |
| フリーランス | オフラインでも案件タスクを整理 | US-005 |
| 一般 PC ユーザー | `.exe` をダブルクリックするだけで使える | US-007 |

## 5. スコープ

### 5.1 In Scope（M1 MVP）

| 項目 | 説明 |
|------|------|
| **単一ユーザー利用** | 1 ユーザーが 1 台の PC で独立して利用 |
| **独立デスクトップアプリ** | サーバー・ブラウザ不要。`.exe` 単体で起動・動作 |
| 単一ボード | 1 つのボード上にカードを自由配置 |
| カード CRUD | 作成・編集（ボタン）・削除（右クリック） |
| **オーバーレイモード** | 指定ディスプレイ全画面・透過・最前面（M1 既定 UI） |
| **カードドラッグ** | ドラッグで画面上の位置を変更 |
| **削除確認設定** | 設定でカード削除時の確認ダイアログ ON/OFF |
| **アプリ終了** | 画面右上 × ボタン |
| ローカル永続化 | ユーザー PC 内 JSON ファイルへの自動保存 |
| Windows `.exe` | PyInstaller による単一実行ファイルのビルド |
| **ディスプレイ指定** | 設定画面で表示先モニターを選択・保存 |

### 5.2 Out of Scope（M1 MVP）

| 項目 | 延期先 | 理由 |
|------|--------|------|
| ウィンドウモード | M2 | M1 はオーバーレイモードを既定とする |
| デスクトップモード | M2 | オーバーレイモードを優先 |
| 3 列カンバン | M2 | M1 は自由配置カード |
| 列間移動 | M2 | M1 は位置ドラッグのみ |
| 表示モード切替 UI | M2 | M1 はオーバーレイモード固定 |
| 複数ユーザー・共同編集 | M3 | 初期スコープは単一ユーザー |
| ユーザー認証・ログイン | M3 | アカウント不要の独立アプリを優先 |
| クラウド同期・ネットワーク API | M3 | ローカル完結を優先 |
| 列間ドラッグ＆ドロップ | M2 | M1 は位置ドラッグのみ |
| 複数ボード | M2 | MVP は単一ボードで価値検証 |
| macOS / Linux 配布 | M3 | 初期スコープは Windows `.exe` |

### 5.3 仮定と制約

| # | 種別 | 内容 |
|---|------|------|
| A-1 | 仮定 | ユーザーは **Windows 11 以降** を使用 |
| A-2 | 仮定 | 1 ユーザー・1 PC・1 ボードあたりカード 100 件以下 |
| A-3 | 仮定 | 同時に複数プロセスで同一データファイルを開かない |
| C-1 | 制約 | **単一ユーザーの独立デスクトップアプリ**であること（M1 の根幹） |
| C-2 | 制約 | 配布物は **Windows `.exe` 単一ファイル** とする |
| C-6 | 制約 | **対応 OS は Windows 11 以降**（Windows 10 以下は非サポート） |
| C-3 | 制約 | MVP のランタイム依存は Python 標準ライブラリのみ |
| C-4 | 制約 | GUI は tkinter を使用 |
| C-5 | 制約 | ネットワーク通信・外部サービス連携を実装しない（M1） |

## 6. 競合との差別化

| 観点 | 既存ツール | Petatto-Kanban |
|------|-----------|----------------|
| 導入 | アカウント登録・Web ログインが必要な場合が多い | `.exe` を実行するだけ。単一ユーザーで即利用 |
| 依存 | クラウド・常時ネットワーク | **独立デスクトップ**。オフライン完結（M1） |
| 機能量 | 多機能で学習コストが高い | 必要最小限に絞る |
| 操作感 | 多様 | 「ペタッと」貼る軽快さを重視 |

## 1. ビジョン

**「タスクをペタッと貼って、サッと進める」**

Petatto-Kanban は、Windows デスクトップ上で動作するカンバン方式タスク管理アプリである。  
付箋を貼るような軽快な操作感を核に、個人のタスク整理と進捗管理をシンプルに行える。

---

## 2. 目的

| # | 目的 | 成功指標 |
|---|------|----------|
| P-1 | 直感的なタスク管理 | 初回利用者が 5 分以内にカード作成・移動を完了できる |
| P-2 | ローカル完結 | インストール後、ネットワークなしで利用できる（MVP） |
| P-3 | 手軽な配布 | Windows `.exe` 1 ファイルで配布・起動できる |

---

## 3. 対象ユーザー

| ペルソナ | ニーズ | 関連 US |
|----------|--------|---------|
| 個人開発者 | 個人プロジェクトの TODO をシンプルに管理 | US-001, US-003 |
| フリーランス | 複数案件の進捗を視覚的に把握 | US-005 |
| 一般 PC ユーザー | インストールが簡単なデスクトップツール | US-007 |

## 4. スコープ

### 4.1 In Scope（M1 MVP）

| 項目 | 説明 |
|------|------|
| 単一ボード | 1 つのカンバンボードを表示・操作 |
| 3 列カンバン | To Do / In Progress / Done |
| カード CRUD | 作成・編集・削除 |
| 列間移動 | コンボボックスによる移動（MVP） |
| ローカル永続化 | JSON ファイルへの自動保存 |
| Windows .exe | PyInstaller によるビルド |

### 4.2 Out of Scope（M1 MVP）

| 項目 | 延期先 | 理由 |
|------|--------|------|
| ドラッグ＆ドロップ | M2 | tkinter DnD は実装コストが高い |
| 複数ボード | M2 | MVP は単一ボードで価値検証 |
| ユーザー認証・同期 | M3 | ローカル完結を優先 |
| macOS / Linux 配布 | M3 | Windows 優先 |
| チーム共同編集 | M3 | 個人利用を優先 |

### 4.3 仮定と制約

| # | 種別 | 内容 |
|---|------|------|
| A-1 | 仮定 | ユーザーは Windows 10 以降を使用 |
| A-2 | 仮定 | 1 ボードあたりカード 100 件以下 |
| C-1 | 制約 | MVP のランタイム依存は Python 標準ライブラリのみ |
| C-2 | 制約 | GUI は tkinter を使用 |

---

## 5. 競合との差別化

| 観点 | 既存ツール | Petatto-Kanban |
|------|-----------|----------------|
| 導入 | アカウント登録が必要な場合が多い | `.exe` を実行するだけ（MVP） |
| 機能量 | 多機能で学習コストが高い | 必要最小限に絞る |
| 操作感 | 多様 | 「ペタッと」貼る軽快さを重視 |

## UC-001: メインウィンドウ

| 属性 | 値 |
|------|-----|
| 関連 FR | FR-001, FR-002 |
| 関連 AC | AC-001-01, AC-002-01 |

## UC-002: ヘッダー

| 属性 | 値 |
|------|-----|
| 関連 FR | FR-001, FR-008, FR-009 |

| 要素 | 操作 | 結果 |
|------|------|------|
| ボード名ラベル | — | 現在の `board.name` を表示 |
| 「保存」ボタン | クリック | `save_board()` + 完了ダイアログ |
| 「再読み込み」ボタン | クリック | `load_board()` + 画面再描画 |

## UC-003: 列レイアウト

| 属性 | 値 |
|------|-----|
| 関連 FR | FR-002 |

```
┌─────────────────────────────────────────────────────────┐
│  Header: ボード名                    [再読み込み] [保存] │
├──────────────┬──────────────┬───────────────────────────┤
│   To Do      │ In Progress  │   Done                    │
│ ┌──────────┐ │ ┌──────────┐ │ ┌──────────┐             │
│ │ Card     │ │ │ Card     │ │ │ Card     │             │
│ └──────────┘ │ └──────────┘ │ └──────────┘             │
│ [+ カード]   │ [+ カード]   │ [+ カード]                │
└──────────────┴──────────────┴───────────────────────────┘
```

| 要素 | 仕様 |
|------|------|
| 列数 | 3（MVP 固定） |
| 列幅 | 均等配分（`uniform="columns"`） |
| カード一覧 | 列内スクロール可能 |

---

## UC-004: カードコンポーネント

| 属性 | 値 |
|------|-----|
| 関連 FR | FR-003, FR-004, FR-005, FR-006 |

| 要素 | 操作 | 結果 |
|------|------|------|
| タイトル | — | 太字、`wraplength=220` |
| 説明 | — | 存在時のみ表示、グレー文字 |
| 「編集」 | クリック | 編集ダイアログ（タイトル・説明） |
| 移動先コンボボックス | 選択 | 選択列へ移動、選択肢をリセット |
| 「削除」 | クリック | 確認ダイアログ → 削除 |

**移動先コンボボックス**
- 初期表示: `"移動先..."`
- 選択肢: 自列以外の列名
- 選択後: `"移動先..."` にリセット

---

## UC-005: カード追加ダイアログ

| 属性 | 値 |
|------|-----|
| 関連 FR | FR-003 |
| 関連 AC | AC-003-01, AC-003-02 |

| 属性 | 値 |
|------|-----|
| 種別 | `simpledialog.askstring` |
| タイトル | `"カード追加"` |
| プロンプト | `"タイトルを入力してください:"` |
| キャンセル | カード作成しない |

---

## UC-006: カード編集ダイアログ

| 属性 | 値 |
|------|-----|
| 関連 FR | FR-004 |
| 関連 AC | AC-004-01 |

| 要素 | 仕様 |
|------|------|
| タイトル入力 | 1 行テキスト |
| 説明入力 | 複数行テキスト（5 行） |
| OK | タイトル空なら警告、保存 |
| キャンセル | 変更破棄 |

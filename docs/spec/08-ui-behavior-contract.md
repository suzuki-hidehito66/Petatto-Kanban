## UC-002: ツールバー

| 属性 | 値 |
|------|-----|
| 関連 FR | FR-003, FR-023 |
| UI 契約 | 旧「ヘッダー」をツールバーに置換（M1） |

| 要素 | 操作 | 結果 |
|------|------|------|
| 「×」ボタン | クリック | `_on_close()` — 保存後にアプリ終了（**右上・最右端**） |
| 「設定」ボタン | クリック | 設定ダイアログ（FR-021, FR-024） |
| 「+ カード」 | クリック | カード追加ダイアログ |

**ツールバーレイアウト（左 → 右）:** + カード | 設定 | **×**

**配置:** 画面右上 `(screen_width - 16, 16)`、`anchor=NE`

## UC-003: カードコンポーネント

| 属性 | 値 |
|------|-----|
| 関連 FR | FR-002, FR-003, FR-004, FR-005, FR-010 |

| 要素 | 操作 | 結果 |
|------|------|------|
| カード枠・説明 | 左クリックドラッグ | 画面上の位置を変更（FR-010） |
| カード全体 | 右クリック離し | **削除処理**（FR-005）。メニューは表示しない |
| タイトル | ダブルクリック | インライン編集（FR-004） |
| タイトル | — | 太字、`wraplength=200`、ドラッグ対象外 |
| 説明 | — | 存在時のみ表示、グレー文字（M1 では編集不可） |

**削除**
- 右ボタンを **離した** とき（`<ButtonRelease-3>`）→ `_delete_card()` を呼び出し
- 右ボタン **押下のみ** では削除しない
- `confirm_delete=true` 時: 確認ダイアログ → 削除
- `confirm_delete=false` 時: 即時削除

**配置**
- `place(x, y)` — 座標は `board.json` に永続化
- 既定幅 `CARD_WIDTH = 220`

## UC-005: タイトルインライン編集

| 属性 | 値 |
|------|-----|
| 関連 FR | FR-004 |
| 関連 AC | AC-004-01 |

| 要素 | 仕様 |
|------|------|
| 開始 | タイトルラベルのダブルクリック |
| UI | ラベルを `tk.Entry` に差し替え（同一カード内） |
| 確定 | Enter キー、または Entry のフォーカスアウト |
| キャンセル | Escape キー（変更を破棄） |
| 検証 | 空タイトルは警告表示し編集継続 |
| 保存 | 確定時に `save_board()` |

## UC-006: 設定ダイアログ

| 属性 | 値 |
|------|-----|
| 関連 FR | FR-021, FR-024 |
| 関連 AC | AC-021-01, AC-024-01 |

| 要素 | 仕様 |
|------|------|
| 表示ディスプレイ | コンボボックス（OS 認識モニター一覧、`readonly`） |
| チェックボックス | 「カード削除時に確認ダイアログを表示する」 |
| 保存 | OK で `settings.json` に `monitor_index` と `confirm_delete` を保存 |
| ディスプレイ変更時 | オーバーレイ全画面を再配置し、カードを再描画 |

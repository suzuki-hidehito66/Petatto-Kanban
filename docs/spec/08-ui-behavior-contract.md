## UC-002: ツールバー

| 属性 | 値 |
|------|-----|
| 関連 FR | FR-003, FR-023 |
| UI 契約 | 旧「ヘッダー」をツールバーに置換（M1） |

| 要素 | 操作 | 結果 |
|------|------|------|
| 「×」ボタン | クリック | `_on_close()` — 保存後にアプリ終了（**右上・最右端**） |
| 「設定」ボタン | クリック | 設定ダイアログ（FR-021, FR-024） |
| 「+ カード」 | クリック | ツールバー付近にカード即時追加し、インライン編集開始（UC-004） |

**ツールバーレイアウト（左 → 右）:** + カード | 設定 | **×**

**配置:** 画面右上 `(screen_width - 16, 16)`、`anchor=NE`

## UC-003: カードコンポーネント

| 属性 | 値 |
|------|-----|
| 関連 FR | FR-002, FR-003, FR-004, FR-005, FR-010, FR-025, FR-014 |

| 要素 | 操作 | 結果 |
|------|------|------|
| カード枠 | 左クリックドラッグ | 画面上の位置を変更（FR-010） |
| カード枠 | 右クリック離し | **削除処理**（FR-005）。メニューは表示しない |
| タイトル | 左クリックドラッグ | 画面上の位置を変更（FR-010） |
| タイトル | 右クリック離し | **削除処理**（FR-005）。メニューは表示しない |
| タイトル | ダブルクリック | インライン編集（UC-005） |
| タイトル | — | 太字、`wraplength=200`。`GROOVE` 枠の内側フレームで表示 |
| 進捗バー | ホバー中スクロールアップ | 進捗率 +10%（最大 100%）（FR-025） |
| 進捗バー | ホバー中スクロールダウン | 進捗率 −10%（最小 0%）（FR-025） |
| 進捗バー | 左クリックドラッグ | 画面上の位置を変更（FR-010） |
| 進捗バー | 右クリック離し | **削除処理**（FR-005） |
| 進捗バー | — | 左から塗りつぶし。0%≈赤 / 50%≈黄 / 100%≈緑。中央に `NN%` 表示 |
| 期限パネル | 左クリックドラッグ | 画面上の位置を変更（FR-010） |
| 期限パネル | 右クリック離し | **削除処理**（FR-005） |
| 期限パネル | ダブルクリック | 期限編集パネル（UC-008） |
| 期限パネル | — | `期限なし` または `YYYY/MM/DD`。当日=黄 / 超過=赤 |

**削除**
- 右ボタンを **離した** とき（`<ButtonRelease-3>`）→ `_delete_card()` を呼び出し
- 右ボタン **押下のみ** では削除しない
- `confirm_delete=true` 時: 確認ダイアログ → 削除
- `confirm_delete=false` 時: 即時削除

**配置・サイズ**
- `place(x, y)` — 座標は `board.json` に永続化
- 最小サイズ `CARD_MIN_WIDTH = 220`、`CARD_MIN_HEIGHT = 120`（タイトル表示より大きいバッファを確保）
- 実際の枠サイズは `max(最小サイズ, winfo_reqwidth/height)` で決定

## UC-004: カード即時追加

| 属性 | 値 |
|------|-----|
| 関連 FR | FR-003 |
| 関連 AC | AC-003-01, AC-003-02 |

| 属性 | 値 |
|------|-----|
| トリガー | ツールバー「+ カード」のクリック |
| 初期タイトル | `新しいタスク`（`DEFAULT_NEW_CARD_TITLE`） |
| 配置 | `_card_position_near_add_button()` — ツールバー直下付近（連続追加時はオフセット） |
| 保存 | 追加直後に `board.json` へ永続化 |
| タイトル編集 | 追加直後に UC-005 のインライン編集を自動開始（全選択・フォーカス） |

## UC-005: タイトルインライン編集

| 属性 | 値 |
|------|-----|
| 関連 FR | FR-004 |
| 関連 AC | AC-004-01 |

| 属性 | 値 |
|------|-----|
| トリガー | タイトルラベルの `<Double-Button-1>`、または FR-003 によるカード追加直後 |
| UI | 同一カード枠内の `Entry` に切り替え |
| 入力 | タイトル（必須） |
| 確定 | Enter、フォーカスアウト、または同一カードのタイトル以外をクリック |
| キャンセル | Escape |

## UC-008: 期限編集パネル

| 属性 | 値 |
|------|-----|
| 関連 FR | FR-014 |
| 関連 AC | AC-014-01, AC-014-02 |

| 属性 | 値 |
|------|-----|
| トリガー | 期限パネルの `<Double-Button-1>` |
| UI | カード外のフロートパネル（`DueDatePicker` — 別ウィンドウではない） |
| 配置 | 期限パネル直下（画面端では上側へ自動調整） |
| カレンダー | 月間表示。日付クリックで確定。**当日の日付ボタンは緑色** |
| 期限なし | 「期限なし」ボタンで `due_date = null` |
| 閉じる | 「閉じる」ボタン、Escape、またはパネル外クリックでキャンセル |
| 保存 | 日付選択・期限なし確定時に `board.json` へ永続化 |

## UC-006: 設定ダイアログ

| 属性 | 値 |
|------|-----|
| 関連 FR | FR-021, FR-024 |
| 関連 AC | AC-021-01, AC-024-01 |

| 要素 | 仕様 |
|------|------|
| 表示ディスプレイ | コンボボックス（OS 認識モニター一覧、`readonly`） |
| チェックボックス | 「カード削除時に確認ダイアログを表示する」 |
| 保存 | OK で `settings.json` に `monitor_index` と `confirm_delete` を保存 |
| ディスプレイ変更時 | オーバーレイ全画面を再配置し、カードを再描画 |

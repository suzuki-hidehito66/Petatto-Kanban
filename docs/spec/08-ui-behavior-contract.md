## UC-002: ツールバー

| 属性 | 値 |
|------|-----|
| 関連 FR | FR-003, FR-021, FR-023, FR-024 |
| UI 契約 | 旧「ヘッダー」をツールバーに置換（M1） |

| 要素 | 操作 | 結果 |
|------|------|------|
| 「×」ボタン | クリック | `_on_close()` — 保存後にアプリ終了（**右上・最右端**） |
| 「設定」ボタン | クリック | 設定ダイアログ（削除確認 ON/OFF） |
| 「+ カード」 | クリック | カード追加ダイアログ |
| ディスプレイ選択 | コンボボックス変更 | 表示先モニター変更・全画面再配置・`settings.json` 保存 |

**ツールバーレイアウト（左 → 右）:** ディスプレイ: [コンボボックス] | + カード | 設定 | **×**

**配置:** 画面右上 `(screen_width - 16, 16)`、`anchor=NE`

## UC-003: カードコンポーネント

| 属性 | 値 |
|------|-----|
| 関連 FR | FR-002, FR-003, FR-004, FR-005, FR-010 |

| 要素 | 操作 | 結果 |
|------|------|------|
| カード全体 | 左クリックドラッグ | 画面上の位置を変更（FR-010） |
| カード全体 | 右クリック | コンテキストメニュー（編集 / 削除） |
| タイトル | — | 太字、`wraplength=200` |
| 説明 | — | 存在時のみ表示、グレー文字 |
| 「編集」 | クリック | 編集ダイアログ（タイトル・説明） |

**削除**
- 右クリック → 「削除」
- `confirm_delete=true` 時: 確認ダイアログ → 削除
- `confirm_delete=false` 時: 即時削除

**配置**
- `place(x, y)` — 座標は `board.json` に永続化
- 既定幅 `CARD_WIDTH = 220`

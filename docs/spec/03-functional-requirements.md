## M1 MVP 要件詳細

### FR-001: ボード表示

| 属性 | 値 |
|------|-----|
| 優先度 | Must |
| ステータス | verified |
| 関連 US | US-001 |
| 関連 AC | AC-001-01 |
| 実装 | `src/petatto_kanban/app.py` |

**説明**  
アプリ起動時に 1 つのカンバンボードをウィンドウ全体に表示する。

**制約**
- ボード名をヘッダーに表示する
- 最小ウィンドウサイズ: 960 × 540 px

---

### FR-002: 列表示

| 属性 | 値 |
|------|-----|
| 優先度 | Must |
| ステータス | verified |
| 関連 US | US-001 |
| 関連 AC | AC-002-01 |
| 実装 | `src/petatto_kanban/models.py`, `app.py` |

**説明**  
デフォルト 3 列（To Do / In Progress / Done）を横並びで表示する。

**制約**
- 列は左から order 昇順
- 各列にスクロール可能なカード一覧を表示

---

### FR-003: カード作成

| 属性 | 値 |
|------|-----|
| 優先度 | Must |
| ステータス | implemented |
| 関連 US | US-002 |
| 関連 AC | AC-003-01, AC-003-02 |
| 実装 | `src/petatto_kanban/app.py` |

**説明**  
各列の「+ カードを追加」から新しいカードを作成する。

**制約**
- タイトルは必須。空文字・空白のみは拒否
- 作成後、当該列の末尾に追加（order = 既存件数）

---

### FR-004: カード編集

| 属性 | 値 |
|------|-----|
| 優先度 | Must |
| ステータス | implemented |
| 関連 US | US-003 |
| 関連 AC | AC-004-01 |
| 実装 | `src/petatto_kanban/app.py` |

**説明**  
カードの「編集」ボタンからタイトルと説明を変更する。

**制約**
- タイトルは必須
- 更新時に `updated_at` を更新

---

### FR-005: カード削除

| 属性 | 値 |
|------|-----|
| 優先度 | Must |
| ステータス | implemented |
| 関連 US | US-004 |
| 関連 AC | AC-005-01 |
| 実装 | `src/petatto_kanban/app.py` |

**説明**  
カードの「削除」ボタンで確認ダイアログ後に削除する。

**制約**
- 削除前に確認ダイアログを表示
- 削除後、列内 order を再採番

---

### FR-006: カード列間移動

| 属性 | 値 |
|------|-----|
| 優先度 | Must |
| ステータス | implemented |
| 関連 US | US-005 |
| 関連 AC | AC-006-01 |
| 実装 | `src/petatto_kanban/app.py` |

**説明**  
コンボボックスで移動先列を選択し、カードを別列へ移動する。

**制約**
- 移動元列は選択肢から除外
- 移動先列の末尾に追加
- 両列の order を再採番

**注記**  
ドラッグ＆ドロップによる移動は FR-010（M2）で提供。

---

### FR-007: データ永続化

| 属性 | 値 |
|------|-----|
| 優先度 | Must |
| ステータス | verified |
| 関連 US | US-006 |
| 関連 AC | AC-007-01, AC-007-02, AC-007-03 |
| 実装 | `src/petatto_kanban/storage.py` |
| データ契約 | [DC-001](./07-data-contract.md#dc-001-boardjson-スキーマ) |

**説明**  
ボードデータを JSON ファイルに保存し、次回起動時に復元する。

**制約**
- 保存先: `%USERPROFILE%\.petatto-kanban\board.json`
- ファイル不存在時はデフォルトボードを生成
- アプリ終了時に自動保存

## スコープ前提

本ドキュメントの M1 要件は、以下の初期スコープ定義に従う。

> **単一ユーザーの独立したデスクトップアプリケーション（`.exe`）**

- ネットワーク API・ユーザー認証・マルチユーザー機能は M1 に含めない
- データは利用者の PC 内にのみ保存する

参照: [01-vision-and-scope.md §2](./01-vision-and-scope.md#2-初期スコープm1-mvpの定義)

## M1 MVP 要件詳細

### FR-001: ボード表示

| 属性 | 値 |
|------|-----|
| 優先度 | Must |
| ステータス | verified |
| 関連 US | US-001 |
| 関連 AC | AC-001-01 |
| 実装 | `src/petatto_kanban/app.py` |

**説明**  
アプリ起動時に 1 つのカンバンボードをウィンドウ全体に表示する。

**制約**
- ボード名をヘッダーに表示する
- 最小ウィンドウサイズ: 960 × 540 px

---

### FR-002: 列表示

| 属性 | 値 |
|------|-----|
| 優先度 | Must |
| ステータス | verified |
| 関連 US | US-001 |
| 関連 AC | AC-002-01 |
| 実装 | `src/petatto_kanban/models.py`, `app.py` |

**説明**  
デフォルト 3 列（To Do / In Progress / Done）を横並びで表示する。

**制約**
- 列は左から order 昇順
- 各列にスクロール可能なカード一覧を表示

### FR-003: カード作成

| 属性 | 値 |
|------|-----|
| 優先度 | Must |
| ステータス | implemented |
| 関連 US | US-002 |
| 関連 AC | AC-003-01, AC-003-02 |
| 実装 | `src/petatto_kanban/app.py` |

**説明**  
各列の「+ カードを追加」から新しいカードを作成する。

**制約**
- タイトルは必須。空文字・空白のみは拒否
- 作成後、当該列の末尾に追加（order = 既存件数）

|------|-----|
| 優先度 | Must |

### FR-006: カード列間移動

| 属性 | 値 |
|------|-----|
| 優先度 | Must |
| ステータス | implemented |
| 関連 US | US-005 |
| 関連 AC | AC-006-01 |
| 実装 | `src/petatto_kanban/app.py` |

**説明**  
コンボボックスで移動先列を選択し、カードを別列へ移動する。

**制約**
- 移動元列は選択肢から除外
- 移動先列の末尾に追加
- 両列の order を再採番

**注記**  
ドラッグ＆ドロップによる移動は FR-010（M2）で提供。

### FR-007: データ永続化

| 属性 | 値 |
|------|-----|
| 優先度 | Must |
| ステータス | verified |
| 関連 US | US-006 |
| 関連 AC | AC-007-01, AC-007-02, AC-007-03 |
| 実装 | `src/petatto_kanban/storage.py` |
| データ契約 | [DC-001](./07-data-contract.md#dc-001-boardjson-スキーマ) |

**説明**

**制約**
- 保存先: `%USERPROFILE%\.petatto-kanban\board.json`
- ファイル不存在時はデフォルトボードを生成
- アプリ終了時に自動保存

### FR-019: デスクトップモード

| 属性 | 値 |
|------|-----|
| 優先度 | Must |
| ステータス | implemented |
| 関連 US | US-009 |
| 関連 AC | AC-019-01, AC-019-02 |
| 実装 | `src/petatto_kanban/display/desktop.py`, `app.py` |
| UI 契約 | [12-display-modes.md §5](./12-display-modes.md#5-デスクトップモードdesktop-mode) |

**説明**  
指定ディスプレイを全画面表示。背景透過でデスクトップが見え、**他ウィンドウより背面**に固定。

**制約**
- **M1 起動時の既定表示モード**
- カンバン UI パネルのみ不透明、それ以外は透過
- Windows 11 以降で Win32 API により Z オーダー背面を設定

### FR-023: アプリ終了

| 属性 | 値 |
|------|-----|
| 優先度 | Must |
| ステータス | implemented |
| 関連 US | US-011 |
| 関連 AC | AC-023-01 |
| 実装 | `src/petatto_kanban/app.py` |
| UI 契約 | [UC-002](./08-ui-behavior-contract.md#uc-002-ヘッダー) |

**説明**  
ヘッダー右上の **×ボタン** でアプリを終了する。終了前にボード・表示設定を自動保存する。

**制約**
- デスクトップモード（タイトルバーなし）でも終了できること
- `WM_DELETE_WINDOW` と同じ `_on_close` 処理を呼ぶ

## US-001: ボードを開く

**As a** 個人開発者  
**I want to** アプリを起動してオーバーレイ上にカードをすぐ見る  
**So that** 他のアプリを使いながら今日のタスクに取りかかれる

| 属性 | 値 |
|------|-----|
| 関連 FR | FR-001, FR-002, FR-020 |
| 関連 AC | AC-001-01, AC-002-01, AC-020-01 |
| ステータス | implemented |
